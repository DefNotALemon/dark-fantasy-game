Myrkfell

The Withering · Godot 4.7 prototype

No browser build yet. This is a Forward Plus 3D open-world slice (caves, combat, day/night). It needs the Godot editor on your machine — a web export would be huge and would drop the renderer the prototype is built on.

Gritty low-poly dark fantasy survival: sword, bow, pick, axe; a forest overworld; a shifting cathedral underground. Open this repo in Godot 4.7 and press F5. Main scene is scenes/World.tscn.

  • WASD move · mouse look · Shift sprint · Space jump / climb
  • LMB attack · RMB block · 1–4 weapons · Q item wheel · Tab menus

Full controls live in the repo README. When a Compatibility / web export exists, it will launch from this same page.
